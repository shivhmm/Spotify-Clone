# 🎵 Spotify Clone

A **Spotify website clone** built using **HTML and CSS**, inspired by the design and layout of Spotify's web player.

This project was created to practice **frontend development, HTML structure, CSS styling, layouts, and UI design**.

### 🛠️ Technologies Used

* HTML5
* CSS3

### ✨ Features

* Spotify-inspired homepage
* Sidebar navigation
* Music playlist sections
* Album and song cards
* Music player interface
* Dark-themed UI inspired by Spotify

### 📌 Note

This is a **practice/educational project** created for learning frontend web development. It is not affiliated with Spotify.
